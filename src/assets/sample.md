# 欢迎使用 Markdown 编辑器

这是一个功能完整的 **Markdown 编辑器**，支持实时预览和语法高亮。

## 功能特性

- ✅ 实时预览
- ✅ 语法高亮
- ✅ 工具栏快捷操作
- ✅ 本地存储
- ✅ 文章管理

## 支持的语法

### 标题
```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 文本样式
- **粗体文本**
- *斜体文本*
- `行内代码`
